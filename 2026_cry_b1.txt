2. Algorithm identification, encryption, and decryption

Examine the following pseudocode:
BEGIN
    INPUT message
    SET result ← ""

    FOR EACH character IN message
        IF character is an uppercase letter THEN
            position ← ASCII(character) − ASCII('A')
            result ← result + CHARACTER(ASCII('Z') − position)

        ELSE IF character is a lowercase letter THEN
            position ← ASCII(character) − ASCII('a')
            result ← result + CHARACTER(ASCII('z') − position)

        ELSE
            result ← result + character
        END IF
    END FOR

    OUTPUT result
END

- Identify the cipher and state whether it uses substitution or transposition.
- Implement the algorithm in Python.
- Encrypt the message "Cyber Security".
- Decrypt the resulting ciphertext and verify that the original message is recovered.
